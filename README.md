# Java Exercises — Part 2

Continuation of my Java studies and exercises.

This repository continues the content from my previous [`java-exercicios`](https://github.com/kemillymotta/java-exercicios) repository.

It was created to keep the next stages of my Java learning organized in a separate project, starting with **Generics** and continuing through other Java Core topics.

## Structure

Exercises and examples are separated into different packages to keep the project organized and avoid conflicts between classes with common names such as `Product`, `Client`, or `Program`.

Example:

```text
src/
├── generics/
│   ├── example01/
│   ├── example02/
│   └── ...
├── set/
├── map/
└── functional/
```
